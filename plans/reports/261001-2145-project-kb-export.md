# Project KB export — 2026-10-01

## Result and acceptance

Admins can use **Xuất KB** from any project knowledge panel (expanded list, detail, or editor) to download the current KB as UTF-8 Markdown. Both DIRECT_CONTEXT and RAG are supported. Downloads use server-saved authoritative knowledge, preserve an open unsaved editing buffer, and expose a safe project filename. Pending requests prevent duplicate clicks; switching project or unmounting cancels and fences late results. Empty knowledge produces a Vietnamese error and no file.

`GET /api/v1/knowledge/projects/{project_id}/knowledge-export` is admin-only and returns `text/markdown; charset=utf-8`, an attachment filename, and `Cache-Control: no-store`. Authentication failures return `401`; non-admin accounts `403`; missing projects `404`; no exportable current knowledge `409`. The OpenAPI media type matches the actual response. CORS exposes only Content-Disposition; origins, credentials policy, and authentication are unchanged.

The read-only leaf service uses one SQLAlchemy statement, so source selection and the authority pointers come from the same database snapshot. DIRECT_CONTEXT preserves saved raw text. Category-authoritative RAG exports ACTIVE revisions with their same-project PUBLISHED backing documents, in canonical catalog order. Legacy RAG exports published normalized source text only from the pointed ACTIVE KB version. Retired, shadow, failed, cleared, orphaned, and foreign sources are excluded. Historical nullable reverse KB owners remain compatible with runtime-readable projects; an explicitly different owner is rejected. Runtime credentials, embeddings, revision metadata, and candidate records are not serialized.

The existing **Tải mẫu KB đầy đủ** action had a confirmed transport bug: the backend returned text/plain, while the adapter attempted JSON decoding. It now reads authenticated text correctly and preserves `mau-kb-du-an.md`. It shares pending, error, cancellation, project ownership, and Blob cleanup behavior with the export action. The blank template remains separate from the active KB download.
