Below is a build-ready miniCRM spec for your VFIC recruitment chatbot system, using Tabler + Bootstrap for the admin UI.

Tabler is suitable here because it is a responsive Bootstrap 5 admin template with built-in dashboard layouts, dark mode, forms, tables, charts, maps, and UI components. Tabler Icons are also free/MIT-licensed and can be used for commercial admin UI icons.

1. Product goal

Build a miniCRM + live chat console for VFIC recruiters to:

1. Monitor all Zalo chatbot conversations
2. Take over any chat from chatbot
3. Stop chatbot when recruiter takes over
4. View and manage worker leads
5. Assign leads to recruiters
6. Follow up with interested workers
7. Manage jobs and company knowledge used by chatbot
8. Track basic recruitment and chatbot metrics

The miniCRM should not replace n8n. The correct separation is:

miniCRM = human operation console
n8n = chatbot workflow automation
Supabase/Postgres = source of truth
Zalo OA = communication channel

Human takeover race test

And chatbot is generating a reply
When recruiter clicks Take over
Then conversation.mode becomes HUMAN
And conversation.version increments
And pending bot reply is cancelled
And no bot message is sent to Zalo

And recruiter is assigned

Important rule:

When recruiter takes over, chatbot must stop immediately.

Takeover function:

take_over_conversation(conversation_id, recruiter_id)

This must:

Set conversations.mode = 'HUMAN'
Set conversations.assigned_recruiter_id = recruiter_id
Increment conversations.version
Cancel pending bot outbound messages
Insert system message
Insert audit event
Push realtime update
